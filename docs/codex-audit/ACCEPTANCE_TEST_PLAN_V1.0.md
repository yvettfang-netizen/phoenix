## 1. 验收原则

1. 仅使用虚构测试数据，不录入真实家长、孩子、电话或家庭信息。
2. 测试前记录 Git commit、微信开发者工具版本、基础库版本、设备型号、系统版本、微信版本和测试人。
3. 每个失败项保留截图或录屏、控制台日志、复现步骤和实际结果。
4. 不在本阶段上传代码、发布体验版、部署生产环境或提交微信审核。
5. 不更换、不重绘、不生成 Logo；品牌问题只记录并交由品牌负责人确认。
6. 微信开发者工具的“清除缓存/存储”只允许作用于隔离的模拟器测试数据，不得清理任何真实用户环境。
7. P0/P1 必须阻断验收；P2 可在明确记录、责任人和处理决定后评估是否接受；P3 不影响本轮验收。

### 1.1 结果定义

| 结果 | 定义 |
| --- | --- |
| PASS | 实际结果完全符合预期，控制台无新增 error/warning |
| FAIL | 功能、数据、导航、布局或品牌表现不符合预期 |
| BLOCKED | 因 AppID、设备、权限或外部环境无法执行，不得填写为 PASS |
| NEEDS HUMAN REVIEW | 需要品牌、产品或安全负责人作出判断，工程测试不能代替 |

### 1.2 缺陷等级

| 等级 | 验收定义 |
| --- | --- |
| P0 | 无法启动、核心路径中断、越权、用户数据丢失/泄露或隐私风险 |
| P1 | 核心页面不可用、主要导航失败、严重状态栏遮挡、正式品牌资产错误 |
| P2 | 局部布局、提示、输入边界、空状态或兼容性问题 |
| P3 | 不影响本轮 MVP 的后续优化建议 |

## 3. 微信开发者工具测试步骤

### DEV-01｜导入与配置确认

1. 打开微信开发者工具，不启用上传或提交审核操作。
2. 导入项目根目录 `phoenix-family-os-mvp`。
3. 确认项目类型为“小程序”，基础库选择 3.7.12。
4. 确认当前使用 `touristappid`；不要自动替换成正式 AppID。
5. 确认项目面板能识别 `app.json`、15 个页面和 `sitemap.json`。

通过标准：项目可导入，无配置解析错误，无页面缺失提示。

### DEV-02｜首次清缓存编译

1. 仅在隔离测试环境执行“清除全部缓存/清除工具缓存”。
2. 点击“编译”。
3. 观察编译器、Console、Network、AppData/Storage 面板。
4. 从 Welcome 页面开始，不使用自定义启动页跳过登录。

通过标准：

- 无 WXML、WXSS、JS、JSON 编译错误。
- 无缺失组件、缺失图片、路径大小写或路由错误。
- Welcome 首屏完整显示，Logo、标题、按钮不闪烁或错位。
- Console 无未捕获异常和新增 warning。

### DEV-03｜二次编译与状态保持

1. 完成一次登录和家庭档案保存。
2. 不清除 Storage，再次点击“编译”。
3. 将小程序切入后台，再恢复前台。
4. 关闭并重新打开模拟器会话。

通过标准：登录身份、家庭档案和已保存孩子档案保持；不重复创建数据；页面能恢复到合理入口。

### DEV-04｜页面路由冒烟

依次检查 Welcome、Home、Family Profile、Child Profile、Education Compass、Compass Questionnaire、AI Growth Insight、Timeline、Advisor Request、Mine，以及现有 Admin/Partner 页面能否按既有入口或编译模式打开。

通过标准：无死链、循环跳转、空白页、无法返回或返回到不存在页面的问题。

### DEV-05｜Console 与 Storage 检查

1. 在核心路径每一步观察 Console。
2. 在 Storage 中确认 `PFS_CURRENT_USER_ID` 与 `PFS_DB_V01` 的变化。
3. 连续完成两次页面进入和返回。
4. 确认没有意外清空原有测试记录，也没有同一次点击产生重复记录。

通过标准：Console 无 error/warning；Storage 结构可读取；旧记录保持；无意外重复。

### DEV-06｜基础性能观察

1. 冷启动三次并记录首屏可操作时间。
2. 快速切换 Home、Timeline、Mine 三个 tab。
3. 打开含较长文本的表单和 Compass 页面并快速滚动。

通过标准：无明显长时间白屏、卡死、滚动掉帧或图片反复闪烁。若无法量化性能，只记录观察结果，不伪造指标。

## 6. 页面流程验收

### FLOW-01｜全新用户主流程

前置条件：隔离测试环境；清除模拟器测试数据；位于 Welcome 页面。

| 步骤 | 操作 | 预期结果 |
| ---: | --- | --- |
| 1 | 检查 Welcome 页面 | Phoenix Nova 品牌、产品名、说明和登录按钮完整显示 |
| 2 | 点击“开启家庭成长档案”一次 | 按钮进入 loading，成功后进入 Home，不重复跳转 |
| 3 | 在 Home 点击“建立家庭档案” | 进入 Family Profile，返回导航有效 |
| 4 | 不填写内容直接保存 | 显示必填提示，不写入空家庭数据 |
| 5 | 填写测试家庭数据并保存 | 仅保存一份家庭档案，提示成功并进入 Child Profile |
| 6 | 不填写内容直接保存 | 显示必填提示，不写入空孩子数据 |
| 7 | 填写测试孩子数据并保存 | 仅保存一份孩子档案，并进入 Education Compass |
| 8 | 检查 Compass 页面 | 显示正确孩子姓名、学校和年级；无报告时不显示错误历史记录 |
| 9 | 点击“开始 Education Compass” | 进入 Questionnaire，显示 STEP 1/5 和正确孩子姓名 |
| 10 | 返回 Compass，再返回 Home | 导航栈正常，Home 进度和下一步状态与已保存数据一致 |

FLOW-01 任何一步无法继续、进入错误家庭/孩子、产生重复记录或出现未捕获异常均为 FAIL。

### FLOW-02｜重复进入与编辑

1. 从 Home 再次进入 Family Profile，确认已有内容回填。
2. 修改非关键测试字段并保存，确认更新同一家庭而不是新增家庭。
3. 再次进入 Child Profile，确认孩子数据回填。
4. 编辑后保存，确认安全返回，不产生第二个孩子记录。
5. 重复进入 Compass，确认仍绑定同一孩子。

通过标准：数据更新正确、记录数量不意外增加、返回路径正常。

### FLOW-03｜刷新与恢复

1. 在 Family Profile 输入但不保存，点击返回后重新进入。
2. 在已保存 Family/Child 状态下重新编译。
3. 后台停留后恢复前台。
4. 完全关闭测试会话并重新打开。

通过标准：未保存输入允许丢失但不能生成记录；已保存数据和登录身份必须保持；无循环跳转。

## 7. 异常测试

### ERR-NET｜网络异常

| Case | 操作 | 预期结果 |
| --- | --- | --- |
| NET-01 | DevTools 切为 Offline，冷启动 | 本地页面和品牌资源仍加载，无白屏或资源 404 |
| NET-02 | Offline 状态点击家庭用户登录 | 当前 V0.1 demo fallback 不得永久 loading 或崩溃；记录实际路径 |
| NET-03 | Slow 2G/高延迟下重复登录 | 仅触发一次有效跳转，按钮状态可恢复 |
| NET-04 | 流程中切换 Offline/Online | 已保存本地测试数据不丢失，页面无未捕获异常 |

限制：当前没有正式远程 API，以上用例不能证明生产登录或服务端接口的断网恢复能力。生产网络验收保持 BLOCKED。

### ERR-AUTH｜登录失效

1. 保留测试数据库 `PFS_DB_V01`，仅在隔离模拟器中移除测试会话键 `PFS_CURRENT_USER_ID`。
2. 重新启动小程序并尝试直接进入 Home、Family Profile、Child Profile 和 Compass Questionnaire。
3. 在表单页面打开后再使测试会话失效，然后点击保存/提交。

通过标准：统一返回 Welcome；不写入新数据；无空用户访问、死循环或报错。不得在真实环境执行存储删除。

### ERR-DUP｜重复提交

对登录、家庭保存、孩子保存、Compass 最终提交和咨询预约分别连续快速点击 5–10 次。

通过标准：

- loading/saving 时按钮禁用或后续点击被忽略。
- 家庭、孩子、Assessment、Report、Timeline 和预约记录数量符合一次提交。
- 只发生一次成功跳转，不出现多层重复页面。
- 失败后按钮恢复，可正常重试一次。

### ERR-EMPTY｜空数据与错误入口

| Case | 操作 | 预期结果 |
| --- | --- | --- |
| EMPTY-01 | 新登录但无家庭档案 | Home 显示建立家庭档案入口 |
| EMPTY-02 | 有家庭但无孩子档案 | Home 显示添加孩子入口 |
| EMPTY-03 | 有孩子但无 Compass 报告 | Compass 正常展示，历史报告区域为空而非报错 |
| EMPTY-04 | 直接打开不存在的 Student ID | 提示或安全返回，不创建意外孩子记录 |
| EMPTY-05 | 直接打开不存在的 Report ID | 展示可恢复错误状态，不出现空白页或异常 |
| EMPTY-06 | 缺少 `studentId` 进入 Compass/Questionnaire | 安全返回 Home，不读取其他家庭数据 |

### ERR-INPUT｜非法输入

| Case | 输入 | 预期结果 |
| --- | --- | --- |
| INPUT-01 | 必填字段为空或仅空格 | 阻止保存并显示基础提示 |
| INPUT-02 | 电话输入字母、符号或超过 20 位 | 数字键盘/maxlength 应限制；不得破坏布局或存储结构 |
| INPUT-03 | 年龄输入 0、负数、小数、999 | 记录现状并提交产品规则确认；不得崩溃、越界或执行代码 |
| INPUT-04 | 名称输入超长中文、英文、Emoji | 页面可输入/显示，不能横向溢出或遮挡按钮 |
| INPUT-05 | 文本输入 `<script>`、模板符号、引号和换行 | 只能作为普通文本显示，不得执行、改变路由或破坏页面 |
| INPUT-06 | 文本区域输入至 maxlength | 达到限制后停止增长，保存/返回保持稳定 |
| INPUT-07 | Picker 不选择可选项 | 可选字段保持合理占位；必需流程不产生异常 |

年龄合法范围和正式电话格式尚无经确认的商业规则。INPUT-03 只验证安全与稳定性，实际是否允许保存标记为 NEEDS HUMAN REVIEW，不在本测试计划中擅自定义规则。

## 10. 验收出口标准
