# Phoenix Nova Websites

This directory contains the three coordinated Phoenix Nova website codebases.

| Directory | Site | Production URL |
| --- | --- | --- |
| `phoenix-nova-website-v5` | Phoenix Nova website V5 | https://phoenix-nova-v5-candidate.yvettfang.chatgpt.site |
| `phoenix-digital-world` | Phoenix Nova Digital World / 凤启数字世界 | https://fengqi-research-institute.yvettfang.chatgpt.site |
| `phoenix-east` | Phoenix East / 凤启东方 | https://phoenix-east-candidate.yvettfang.chatgpt.site |

The Digital World and Phoenix East sites link to each other through their
primary navigation and footer entry points. Phoenix Nova website V5 keeps the
Digital World portal entry at the top level.

The folders contain source files and approved public assets only. Generated
dependencies, build output, local runtime caches, and TypeScript build-info
files are intentionally excluded.
