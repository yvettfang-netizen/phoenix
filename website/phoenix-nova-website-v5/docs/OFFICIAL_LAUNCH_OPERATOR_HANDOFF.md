# Phoenix Nova 官网首发交接

## Codex 验收

- 双语咨询页、官网接口和 Canonical 接收服务先在隔离环境用合成邮箱验收。接收回执以数据库提交为准。
- 隔离 PostgreSQL 与 Chrome 已验证双语手机表单、线索入库、幂等、专用写入权限，以及合成员工分配、查看邮箱和完成跟进。正式员工会话需在目标环境连接现有会话存储和 Canonical 签名验证器。服务端会话绑定和签名验收已用合成凭证通过。
- 正式域名的首页 canonical 和双语元数据已加入候选代码。待确认线上运行时、部署提交、移动端及完整索引策略。
- 统计候选仅记录官方主站白名单页面的成功文档请求，按页面和语言计数。不采集访客标识、URL 参数、来源地址或表单内容。Worker 使用可选 `WEBSITE_TRAFFIC` 数据集绑定。生产如果使用其他运行时，要在对应入口确认同一计数逻辑。

## Jimson 人工操作

以下工时是操作时间估算，前提是候选通过验收、人员及供应商权限已齐备，等待审批和 DNS 生效时间另计。

| 顺序 | 事项 | 预计工时 | 验证与回滚 |
| --- | --- | --- | --- |
| 1 | 确认目标站点的实际托管平台、正式域名、环境配置权限及可回滚发布版本 | 20–30 分钟 | 提供部署提交或版本、域名与证书核验结果。保存当前环境配置及上一个健康版本的引用。 |
| 2 | 通过环境机密管理配置接收服务的凭据、独立 binder/writer 账号、加密及 HMAC 密钥，并登记已批准的官网接收契约 | 45–90 分钟 | 使用测试环境确认角色、契约、限流和合成回执。异常时关闭 `WEBSITE_CONSULTATION_ENABLED`，保留已有线索与审计，按凭据生命周期处理密钥。 |
| 2a | 确认现有员工登录的会话读取入口、已批准签名来源和具备调度或顾问权限的验收账户 | 20–40 分钟 | 由 Codex接线并验收有效、无权限及撤权会话。异常时停用员工网关入口并撤销测试授权。 |
| 3 | 配置已批准的中英文隐私政策网址、正式流量统计的数据集与公司读取权限 | 20–40 分钟 | 两个隐私页面应可访问且语言正确。合成验收访问应落到预期环境的数据集。停用统计可移除绑定。 |
| 4 | 仅当核对发现 DNS、证书或域名绑定确需调整时，在 Founder 批准的发布窗口执行 | 20–40 分钟 | 检查 HTTPS、证书域名及 HTTP 到 HTTPS 跳转。保留调整前记录和回切指引。 |

## Founder 发布批准

- 确认实际处理咨询资料的主体、隐私联系渠道、保存期限和权利申请路径，批准双语隐私政策。
- 审阅完整的员工权限和跟进验收、移动端、统计、发布版本和回滚证据。
- 批准生产发布窗口。公开索引范围和启用时间须一并明确。

候选未验证员工登录和生产接收端时，不安排正式上线日期。
