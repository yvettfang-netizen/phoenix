# Phoenix Nova 官网首发交接

## Codex 验收

- 双语咨询页、官网接口和 Canonical 接收服务先在隔离环境用合成邮箱验收。接收回执以数据库提交为准。
- 接收和员工网关可分别通过 `listenConsultationLoopback` 接到现有 HTTPS 反向代理。两个入口各自监听独立的 `127.0.0.1` 端口。代理的上游 `Host` 必须与对应 HTTPS 入口一致。员工虚拟主机继续由既有员工身份验证保护。测试已通过实际环回 HTTP 验证主机隔离和数据库提交回执。目标环境 TLS、代理配置和进程托管须另行验收。
- 隔离 PostgreSQL 与 Chrome 已验证双语手机表单、线索入库、幂等、专用写入权限，以及合成员工分配、查看邮箱和完成跟进。正式员工会话需在目标环境连接现有会话存储和 Canonical 签名验证器。服务端会话绑定和签名验收已用合成凭证通过。
- 正式域名的首页 canonical 和双语元数据已加入候选代码。待确认线上运行时、部署提交、移动端及完整索引策略。
- 正式域名只读复查中，HTTP 返回 308 并跳到 HTTPS。中英文首页返回 200，canonical 和文档语言正确。双方的咨询和隐私地址均返回 404，索引仍关闭。发布后使用 `node scripts/official-launch-preflight.mjs` 复跑这些检查。只有 Founder 明确批准首页索引后才使用 `--index-approved` 验收索引开放状态。
- 统计候选仅记录官方主站白名单页面的成功文档请求，按页面和语言计数。不采集访客标识、URL 参数、来源地址或表单内容。Worker 使用可选 `WEBSITE_TRAFFIC` 数据集绑定。生产如果使用其他运行时，要在对应入口确认同一计数逻辑。
- `/zh/privacy` 和 `/en/privacy` 从运行环境读取批准的双语纯文本。以空行分隔段落，设置 `WEBSITE_PRIVACY_POLICY_ZH`、`WEBSITE_PRIVACY_POLICY_EN` 及 `WEBSITE_PRIVACY_VERSION=website-consultation.v1`。留存 Founder 审阅的文本版本和引用后，才设置 `WEBSITE_PRIVACY_APPROVED=true`。使用这些内建隐私页时，任何一版缺失都会关闭咨询提交。验收夹具里的政策正文是合成文本。
- 联系方式保留期限随 Canonical 接收契约配置。由有权限的配置角色调用 `crm.configure_website_contact_retention`，输入经批准的天数及该契约已登记的隐私保留政策摘要。没有配置时拒绝创建线索。仅为清理调度账号授予 `phoenix_website_contact_retention`，按批准频率调用 `crm.erase_expired_website_contacts()` 并记录批次结果。员工读取会即时拒绝过期数据，清理会去除加密邮箱及其摘要，留下线索、关联请求编号和清理时间。隔离夹具里的 30 天仅用于测试。

## Jimson 人工操作

以下工时是操作时间估算，前提是候选通过验收、人员及供应商权限已齐备，等待审批和 DNS 生效时间另计。

| 顺序 | 事项 | 预计工时 | 验证与回滚 |
| --- | --- | --- | --- |
| 1 | 确认目标站点的实际托管平台、正式域名、环境配置权限及可回滚发布版本 | 20–30 分钟 | 提供部署提交或版本、域名与证书核验结果。保存当前环境配置及上一个健康版本的引用。 |
| 2 | 通过环境机密管理配置接收服务的凭据、独立 binder/writer 账号、加密及 HMAC 密钥，并登记已批准的官网接收契约 | 45–90 分钟 | 使用测试环境确认角色、契约、限流和合成回执。异常时关闭 `WEBSITE_CONSULTATION_ENABLED`，保留已有线索与审计，按凭据生命周期处理密钥。 |
| 2a | 确认现有员工登录的会话读取入口、已批准签名来源和具备调度或顾问权限的验收账户 | 20–40 分钟 | 由 Codex接线并验收有效、无权限及撤权会话。异常时停用员工网关入口并撤销测试授权。 |
| 3 | 将已批准的双语隐私政策放到正式主站对应语言的隐私页，配置咨询链接及正式流量统计数据集 | 20–40 分钟 | 以 `/zh/privacy`、`/en/privacy` 为首发地址，执行发布验收脚本并确认政策内容和语言。合成访问应落到预期环境的数据集。停用统计可移除绑定。 |
| 4 | 仅当核对发现 DNS、证书或域名绑定确需调整时，在 Founder 批准的发布窗口执行 | 20–40 分钟 | 检查 HTTPS、证书域名及 HTTP 到 HTTPS 跳转。保留调整前记录和回切指引。 |

- 审阅完整的员工权限和跟进验收、移动端、统计、发布版本和回滚证据。
- 批准生产发布窗口。公开索引范围和启用时间须一并明确。
