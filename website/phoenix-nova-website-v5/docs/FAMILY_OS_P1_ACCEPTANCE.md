## 隔离环境复验顺序

1. 使用同一教育 Service Project 下的家庭 A 学生、已核验家长账号，同时为家庭 B 配独立账号。可额外为家庭 A 家长配置另一位获授权子女以核验切换范围。
2. 学生进入家序、打开项目、完成自己的待办。家长重新登录，核对授权子女并完成自己的待办。分别重登，核对记录、操作者、时间及一次幂等重放的审计结果。
3. 给学生分派一门启明堂课程和一项 ASKWISE 练习。提交后重新登录核对持久状态和本人反馈。家长只看获授权子女进度摘要。
4. 分别撤销监护 Consent、关系和登录会话，然后尝试读取和写入。家庭 B 对家庭 A 无权，Core 不可用时不返回历史资料、不确定的写请求按同一幂等键重试。
5. 家长在凤启学苑核对所选孩子的课程计划和老师安排。老师已发布的线上或线下方式照实显示，草稿不显示。核对中文和英文及手机版布局。
