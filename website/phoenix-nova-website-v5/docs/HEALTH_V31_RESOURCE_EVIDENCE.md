## 六项价值的使用边界

1. 深港医疗专家资源：只介绍协调了解专科/医生安排的方向。不公开医生姓名、执业资格或排班；医院提供后逐项核验。
2. 国际化语言服务：区分医院自有普通话/粤语/英语服务与另行协调翻译，不承诺每家医院英语诊疗。
3. 医疗费用竞争力：为Founder确认的候选定位。未取得香港/英国与深圳同项目、同服务范围、同币种日期和排除项的可比报价；不得发布固定比例或把“可能”写成已证实比较结论。具体报价比较仍HOLD。
4. 舒适住院环境：只能用“部分机构/依实际房型”表达。无禾正真实房型图片使用授权，不采用网络医院病房图或将艺术图标为禾正病房。
5. 预约便利：表达提前沟通和准备效率，不承诺零等待、即时接诊、保证入住或固定时限。
6. 保险衔接：仅行政协助；保障、预授权、直付和赔付由保险机构逐案确认，公开资料不等于该客户保单适用。

## 尚待医院 / Founder 提供

- 合作协议、允许公开使用的合作名称与范围、当前服务联系人；未有证据前不出现“官方合作医院”。
- 香港/内地医生现行执业与专科证明、出诊地点/时段、医院核验日期与公开授权。
- 医院自有语言服务清单，英语诊疗/翻译的区别、预约条件及费用。
- 可公开房型、设施、陪护规则、实时可用性及图片权利证明。
- 逐项目报价版本、日期、包含/排除、第三方费用，以及同口径跨地区可比依据。
- 保险机构、保单及服务适用条件、资料要求和预授权流程。

上述资料缺失不阻止本轮前端候选审查；阻止具体医院名单/报价比较、服务承诺或生产发布。六项卡片保留条件限定，不把某医院的个别条件推广为整个地区承诺。
