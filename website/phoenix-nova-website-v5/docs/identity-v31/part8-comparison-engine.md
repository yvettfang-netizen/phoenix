# 第八部分：四国检索与比较引擎增量

本增量在现有 Identity V3.1 Draft 候选上补齐检索、比较与报告能力，仅支持已批准的 KN / AR / VU / ST；不改变 Compass 评估、已有页面主数据、发布闸门或数据库迁移。

## 实现范围

- 中英文中心标题、双语国家卡片、国旗标识、法律/运营状态、投资方式、家庭及居住条件、核实日期、详情与比较入口。
- 保留十类基础筛选，增加原币金额上下限及五类家庭/六类关注条件。条件只匹配明确核实资料；不推断个人资格，不生成推荐排名。
- 金额必须有对应 `field_sources.minimum_investment` 当前官方证据。来源日期不能晚于今天，记录复核期限不能过期。空金额不会变成零。区间必须选择币种，跨币种或不同投资类别不能按数额假装同等成本。
- 不提供换汇。不发生换算时明确显示“保留原币、未换算、无适用汇率”；不虚构汇率、统计日期或换算成本。政府、尽调、家庭附加、护照、专业服务与第三方费用分别列示。
- 2–4 国比较共用纯函数引擎，未知、重复、超量及非公民旅行文件有明确处理。正式比较要求已发布记录与当前官方来源，逐字段缺证据则显示待核实。内部预览可审核候选，但不能变为正式比较结果。
- 比较报告包含选定国家、法律/运营/受理/签发状态、投资与分项费用、家庭、居住、国籍与护照、双重国籍、旅行资料、税务边界、风险、待核实事项、官方来源及日期。可下载 JSON 或打印/保存 PDF；内部报告有不可对外发布状态。
- 详情页增加 A–H 信息栏目及每节来源、审核与更新时间提示。缺失字段不补猜测数据。电子签证、ETA、落地签和免签分别表示；正式字段来源不充分时保持未知。
- 数据字典增加可选 `planning_details`、`field_sources` 及独立旅行安排字段。旧格式继续兼容，CSV/XLSX 中结构化字段用 JSON 单元格，未填写新字段保持缺失。

## 安全与信息边界

报告与家庭筛选只在当前页面运行；刷新清空，不保存个人档案，不创建客户/家庭/服务项目，不收集护照、资金或身份文件。没有新增 CRM、Founder OS 或 Family OS 写入与统计收集。

前轮的真实资料、法律复核、持久化导入/审批 adapter、Canonical 契约、依赖安全修复及 Founder 发布批准等 HOLD 不因本增量自动解除。四国真实记录仍为 IMPORT_REVIEW，无 ACTIVE；正式目录保持未发布。

## 验证入口

- `tests/cbi-comparison.test.mjs`：正式与审核选择隔离、过期/内部证据、非公民证件、原币金额区间、明确家庭类别、分项费用、状态、税务与报告声明。
- `tests/cbi-import.test.mjs`：扩展字段解析、三个格式、错误枚举、字段级来源、旧模板兼容。
- `tests/cbi-part8-browser.mjs`：双语五种宽度、区间与无证据条件、刷新清空、真实 JSON 报告下载、非法选择及无写入。
- 既有 Identity / CBI / 导入 / GEO 浏览器回归继续运行；完整 CI 以本轮最终 GitHub SHA 为准。

## 尚需真实资料和批准的事项

四国完整官方内容、法律与实际开放状态、法定费用及各自币种、家庭与居住规则、官方和观察周期的独立证据、旅行安排及限制、国旗正式图片资产、政策文章与逐答案 FAQ 来源仍需审核资料。未生成无来源国家文章、免签权益、投资金额、换汇表或可立即申请承诺。
