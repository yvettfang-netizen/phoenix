# Phoenix application workspace

This directory is the target application ownership map. Existing application
source remains in its established repository paths until a separately reviewed
move is approved. The files below are routing manifests, not duplicate
implementations.

| Target boundary | Current source |
|---|---|
| `apps/website/` | `website/` |
| `apps/compass/` | `Phoenix Compass/` |
| `apps/family-os/` | `Phoenix Family OS/` |
| `apps/founder-os/` | Preserved existing Founder OS assets; no relocation or redevelopment in this change |

All application domains use the Canonical database boundary documented in
`docs/database/CANONICAL_DATABASE_AUTHORITY_V1.0.md`.
