# MVP Acceptance Checklist

## Family activation

- [x] 家庭用户能进入小程序并完成微信登录握手。
- [x] 能创建并再次编辑 Family Profile。
- [x] 能创建并再次编辑 Child Profile。

## Education Compass

- [x] 只有 Education Compass 可用。
- [x] 问卷覆盖基本阶段、优势、挑战、兴趣、家长期待、未来目标与行动支持。
- [x] 未完成当前步骤时不能继续。
- [x] 完成后生成结构化 Student Growth Insight。

## Relationship loop

- [x] 报告自动保存至 Family OS。
- [x] 档案、Compass、报告、顾问申请自动写入 Timeline。
- [x] 家庭能主动请求 Advisor Follow-up。
- [x] 顾问能查看家庭、孩子、报告、时间线与联系申请。
- [x] 顾问能添加备注和 Follow-up Status。

## Scope control

- [x] 无商城、支付、保险或医疗记录。
- [x] 无 Partner Portal 与 Partner Management。
- [x] Partner / Permission 为空模型。
- [x] 首页是家庭成长中心，不是服务菜单。

## 上线前必须补齐

- [ ] 认证小程序 AppID、隐私协议与用户授权说明。
- [ ] 服务端 OpenID 换取、角色鉴权与数据隔离。
- [ ] 云数据库备份、审计日志和数据删除机制。
- [ ] 真实 AI 云函数的脱敏、内容安全与人工兜底。
- [ ] 手机号验证、顾问企业身份验证和顾问联系 SLA。
- [ ] 7/30 日回访埋点和留存指标看板。
